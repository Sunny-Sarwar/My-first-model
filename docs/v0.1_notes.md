এই version-এ মূল লক্ষ্য ছিল:

- Text → Token IDs

---

🔤 1. Tokenizer

"tokenizer.py" text-কে token ID-তে এবং token ID-কে আবার text-এ রূপান্তর করে।

Encoder

"I am"
    ↓
[1, 6]

Decoder

[16]
    ↓
"love"

Tokenizer-এর vocabulary-এর প্রতিটি token-এর একটি numerical ID রয়েছে।

---

🧮 2. Embedding

প্রতিটি token ID একটি vector-এর মাধ্যমে represent করা হয়।

বর্তমান embedding size:

embedding_size = 8

অর্থাৎ প্রতিটি token একটি 8-dimensional vector হিসেবে model-এর মধ্যে প্রবেশ করে।

---

🧠 3. Mean Pooling

একটি input sequence-এর সব token embedding-এর average নেওয়া হয়।

embedded_input.mean(axis=0)

এটি পুরো input sequence-কে একটি single vector-এ পরিণত করে।

---

⚡ 4. Linear Layer

Mean-pooled vector-এর উপর একটি linear transformation করা হয়:

scores = hidden @ weights + bias

এর ফলে vocabulary-এর প্রতিটি token-এর জন্য একটি score পাওয়া যায়।

---

📊 5. Softmax

Scores-গুলোকে probability distribution-এ পরিবর্তন করার জন্য softmax ব্যবহার করা হয়েছে।

probabilities = softmax(scores)

ফলে প্রতিটি possible next token-এর probability পাওয়া যায়।

---

📉 6. Loss Function

Model যে target token-এর probability দিয়েছে, তার উপর cross-entropy loss ব্যবহার করা হয়েছে:

loss = -np.log(probability)

Target token-এর probability যত বেশি হয়, loss তত কম হয়।

---

🔬 7. Numerical Gradient

v0.1-এ analytical backpropagation ব্যবহার করা হয়নি।

তার পরিবর্তে finite difference / numerical gradient ব্যবহার করা হয়েছে।

মূল ধারণা:

weight একটু কমাও
      ↓
loss দেখো

weight একটু বাড়াও
      ↓
loss দেখো

দুই loss-এর পার্থক্য থেকে gradient estimate করো

ব্যবহৃত epsilon:

epsilon = 0.0001

Gradient-এর ধারণাটি ছিল:

gradient ≈ (loss_plus - loss_minus) / (2 × epsilon)

---

🔄 8. Training

Training-এর সময় numerical gradient ব্যবহার করে weights update করা হয়েছে।

Learning rate:

learning_rate = 0.1

Update rule:

weight = weight - learning_rate × gradient

v0.1-এ মোট:

100 epochs

চালানো হয়েছে।

Training চলার সময় loss ধীরে ধীরে কমেছে।

উদাহরণ:

Epoch: 96  Loss: 0.5797
Epoch: 97  Loss: 0.5759
Epoch: 98  Loss: 0.5722
Epoch: 99  Loss: 0.5685
Epoch: 100 Loss: 0.5649

এটি দেখায় যে model training data-এর pattern কিছুটা শিখেছে।

---

💾 9. Model Saving

Training শেষে model-এর parameters ".npz" file-এ save করা হয়েছে।

np.savez(
    "sunnygpt_model.npz",
    embedding=embedding,
    weights=weights,
    bias=bias
)

Saved parameters:

- "embedding"
- "weights"
- "bias"

---

📂 10. Model Loading

Saved model আবার load করা যায়:

loaded_model = np.load("sunnygpt_model.npz")

embedding = loaded_model["embedding"]
weights = loaded_model["weights"]
bias = loaded_model["bias"]

এতে আবার নতুন করে training না করেও saved parameters ব্যবহার করে prediction করা যায়।

---

🤖 11. Prediction

User-এর input tokenize করার পর model next token predict করে।

Example:

Input:
I am

Input IDs:
[1, 6]

Prediction:
love

Model vocabulary থেকে সর্বোচ্চ probability-যুক্ত token নির্বাচন করে:

predicted_id = np.argmax(probabilities)

তারপর tokenizer সেটিকে text-এ ফিরিয়ে দেয়।

⚠️ Current Limitations

SunnyGPT v0.1 একটি educational mini language model। এটি ChatGPT-এর মতো large language model নয়।

বর্তমান model-এর limitations:

- Model খুবই ছোট।
- Training data খুব সীমিত।
- Tokenizer খুব basic।
- Token-এর order সরাসরি model-এ রাখা হয় না।
- Mean pooling ব্যবহার করা হয়েছে।
- Self-attention নেই।
- Transformer নেই।
- Causal masking নেই।
- Analytical backpropagation নেই।
- বর্তমান training-এ numerical gradient ব্যবহার করা হয়েছে, যা খুব slow।
- v0.1 training-এর সময় মূলত weights update করা হয়েছে।
- Model-এর language understanding অত্যন্ত সীমিত।
